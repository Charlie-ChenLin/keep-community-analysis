# 真人编码字段与代码速查

本页只说明字段，不含真实正文或已填正式标签。请配合[人工编码入口](../../人工编码开始这里.md)和[冻结手册](../../分类编码手册_v1.md)使用。中文简称用于找列，类别边界仍以手册为准。

## 原 CSV 字段

| 字段 | 填写方式 |
| --- | --- |
| `sample_id` | 原样保留的样本编号；不查真实身份。 |
| `fulltext` | 原样保留的完整清理正文；逐条通读，不补看图片、标签或其他帖子。 |
| `observation_state` | `readable`、`insufficient`、`empty` 三选一。 |
| `domain_state` | `specified`、`unspecified`、`uncertain`、`unavailable` 四选一。 |
| 下列 21 个标签列 | 每格填 `0`、`1` 或大写 `U`；空白表示还没填，不等于 `0`。 |
| `codebook_sha256` | 冻结码本的 hash，原样保留，不由编码者重算或替换。 |

`1` 表示正文有支持该类的证据；`0` 表示信息足够且已完成判断，未检出该类；`U` 保留不可判断与未决歧义。`empty` / `insufficient` 时填 `domain_state=unavailable`，21 个标签全 `U`；`unspecified` / `unavailable` 的六个领域标签全 `U`。可读但领域未指明，并不妨碍单独判断表达行为。

## 私有备注表字段

现有出表脚本未生成 `evidence` / `note` 列。请使用私下随包提供的空备注表；也可按以下字段另建表，与原 CSV 一并私下交回。每个阳性标签至少一条记录；有多个独立证据片段可分多行记录。没有逐字证据的未决项可留空 `evidence`，在 `note` 中说明。

| 字段 | 含义 |
| --- | --- |
| `sample_id` | 与原 CSV 完全一致。 |
| `label_code` | 对应的 `d_…` 或 `f_…` 代码；整行状态问题可填 `observation_state` / `domain_state`。 |
| `evidence` | 原文中足以支持判断的最短连续片段，逐字保留否定、主体、时间和语境；不拼接成不存在的句子。 |
| `note` | 解释 `U`、其他槽的具体缺口、歧义候选、引用/梦境/假设等；解释与原文证据分开。 |

备注表随 A/B 所属关系区分编码者；不要把证据片段、备注或填写完成表上传公开仓库。两份初判交回后才进入分歧复核。现有评估器读取原 CSV 的状态和 21 标签，尚不读取本备注表，不会自动验证证据内容。
